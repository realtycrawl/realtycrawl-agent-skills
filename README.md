# RealtyCrawl agent skills

Install `skills/realtycrawl` into your agent’s skills directory. The skill describes capability discovery, bounded requests, idempotency and real estate data provenance.

Set `REALTYCRAWL_API_KEY` in your agent’s protected environment. Never put credentials in prompts, source files or commits.

- Documentation: https://docs.realtycrawl.dev
- MCP: https://github.com/realtycrawl/realtycrawl-mcp
- Canonical skill: https://realtycrawl.dev/agent-onboarding/SKILL.md

The 200-platform catalog and 43-operation specification include research coverage. Only active capabilities are usable.
